# /packages

Published npm packages for the Astryx design system.

<!-- SYNC: When files in this directory change, update this document. -->

| Directory | Package                 | Purpose                                                                |
| --------- | ----------------------- | ---------------------------------------------------------------------- |
| `core/`   | `@blue-patterns/core`    | Core UI components, theme system, and utilities                        |
| `cli/`    | `@blue-patterns/cli`     | CLI tooling: component docs, templates, scaffolding, codemods          |
| `build/`  | `@blue-patterns/build`   | Build plugins for StyleX source builds (Babel, PostCSS, Vite)          |
| `themes/` | `@blue-patterns/theme-*` | Visual themes (neutral, butter, chocolate, matcha, stone, gothic, y2k) |
| `vega/`   | `@blue-patterns/vega`    | Vega/Vega-Lite chart wrapper (canary only)                             |
| `charts/` | `@blue-patterns/charts`  | Chart components — themeable wrappers over a peer engine (canary only) |
| `lab/`    | —                       | Experimental components (not published)                                |
